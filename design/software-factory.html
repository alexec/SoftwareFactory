Notifications and routing

At the Mac, a banner with the options as actions. Away, the iPhone gets it through iCloud. The answer comes back the same way and the agent carries on.

A question finds you where you are
The factory knows whether you are at the Mac. If you are, the question is a banner there and you answer from it. If you are not, it goes to the iPhone and you answer from the notification. Either way the decision lands in the store and the agent, blocked on escalation.await, carries on.

How it is routed
1 · An agent raises a questionescalation.raise writes it to the store. The agent calls escalation.await and stops.
↓
2 · The Mac decides whether you are hereHere means: the screen is unlocked and there was a keystroke or click in the last two minutes. Nothing more clever than that; it is cheap and it is right most of the time.
3a · HereA macOS notification with the options as its actions. Choose one and it is recorded. If it is still unanswered after 90 seconds, it goes to the iPhone as well.
3b · Not hereThe question syncs to iCloud and CloudKit pushes a notification to the iPhone, no server of ours. The options are the notification’s actions; a tap records the decision.
↓
4 · The decision comes back the same wayiCloud carries it to the Mac; the store updates; escalation.await returns and the agent carries on. Whichever device answered first wins; the other sees it answered.
What this needsThe store syncs through the person’s own iCloud (CloudKit, private database), so both apps read the same questions and decisions. The iPhone app is a client of that store, not of the MCP server; the Mac is the only factory. The first version of the iPhone app is the questions list and its notifications; the rest of the suite can follow if it earns its place.

Data model and MCP tools

The proposal to review: eight entities and the tool set.

The factory, and the tools agents get
A proposal. One MCP server owns the store; the Mac app and every agent are clients of it. The app never knows what an agent runs on.
Factory
This Mac. Memory, CPU, swap, load, the throttle, and the capacity verdict.
memorycpuswapverdictthrottle
Project
A product being built, identified by its folder. Phase, tier, backlog.
idnamepathphasetier
Task
Feature, bug or chore on a backlog, in rank order. One agent on it at a time.
kindstaterankagentlog[]
Agent
A registered worker: name, project, task, last check-in, leases.
nameprojecttaskseenleases[]
Escalation
A question with options, one recommended. Answered by a Decision.
questionoptions[]recommended
Decision
The chosen option, who chose it, when. Kept forever.
optionbyatnote

Something shared, with N slots and a longest lease.

Lease
One slot, one agent, until a time. Expires on its own.

PROJECTS
project.listEvery project, with phase and who is on it. project.addA folder becomes a project. project.updateName, phase, tier.
TASKS
task.listA project’s backlog in rank order. task.nextThe top task nobody is on. task.addFeature, bug or chore, ranked last. task.claimI am on this now. task.statusbacklog · in progress · done, with a note. task.logA line about what happened. task.rankMove a task above or below another. task.removeGone, with a reason.
AGENTS
agent.registerWho I am, which project. Returns my id. agent.checkinHeartbeat: what I am on. Every few minutes. agent.deregisterI am finished. Releases my leases.
ESCALATIONS
escalation.raiseQuestion, context, options, my recommendation. escalation.awaitBlock until decided; returns the Decision. escalation.listOpen questions, mine or everyone’s.
RESOURCES
resource.listEvery resource, free slots, who holds what. resource.leaseOne slot for up to N minutes, why. Returns a lease or a queue position. resource.renewMore time on a lease I hold. resource.releaseGive it back early.
FACTORY
factory.statusMemory, swap, CPU, compiles, verdict. factory.ask"Can I start a compiler?" · "a simulator?" · "a model?" Yes, wait, or no, and why. factory.throttleRead the limits. Only the person sets them.
RULES
Every call carries the agent id from agent.register. A registered agent that misses three check-ins is marked gone and its leases expire. Leases are time-bound; the server takes back what runs out. escalation.await is how the answer reaches the agent: nothing is pushed, the agent waits. Deleting a project or a decision is not a tool; the person does that in the app.
